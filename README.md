# Peineta

App para peluquerías y barberías: agenda de turnos, clientes, recordatorios por WhatsApp, puntos y caja.

- `/` landing con lista de espera (Supabase `lista_espera`) y Pixel de Meta.
- `/terminos.html`, `/privacidad.html`, `/arrepentimiento.html` (botones de arrepentimiento y baja, Disposición 954/2025).
- Backend: Supabase proyecto `peineta` (sa-east-1). Publicación: Netlify, sitio `peineta`.
